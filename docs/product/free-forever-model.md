# Free Forever Model

## Rule
All product features are free for all users.

## Donations
Donations are optional and must not unlock functionality.

## Allowed Donation Benefits
- Thank-you badge.
- Supporter mention if user opts in.
- Receipt email.

## Forbidden
- Paywalled AI.
- Paywalled vault.
- Paywalled export.
- Paywalled collaboration.
- Paywalled privacy.
